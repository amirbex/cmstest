# AtoZ Content Studio — نسخه ۷

استودیوی **عملیات محتوا** برای برند AtoZ.FnB: فایل پلن شما می‌شود منبع حقیقت، و برنامه
از همان‌جا تقویم، صف تولید، استودیو تدوین، زیرنویس خودکار و داشبورد داده می‌سازد.

> مدل دادهٔ نسخهٔ ۷ همان چیزی است که در فایل پلن شما هست: **بچ → ایده → دارایی → انتشار**.
> ۱۹ ایده، ۲۵ دارایی و ۴۸ انتشار از `ATZ-B-M01-W01-P1` بدون هشدار وارد می‌شوند.

## چه چیزی در نسخهٔ ۷ اضافه شد

| اتاق | کار |
|---|---|
| **داشبورد** `#command` | وضعیت هفته، آمادگی تولید، نرخ‌های واقعی، ورود فایل پلن |
| **تقویم** `#calendar` | کلید تقویم، جابه‌جایی، تعویق، ثبت انتشار |
| **صف تولید** `#production` | ایده + راهنمای ساخت ← کانسپت زمان‌بندی‌شده با چک‌لیست آمادگی |
| **استودیو تدوین** `#editor` | بوم صحنه، تایم‌لاین بدون شکاف، زیرنویس خودکار و سوختن روی ویدیو |
| **کتابخانهٔ قالب‌ها** `#templates` | ۱۲۰۰ رسپی حرکت از ۱۴ intent × ۸ حرکت × ۴ چیدمان × ۳ سبک |
| **مخزن دارایی** `#assets` | آپلود با نوار پیشرفت، فشرده‌سازی خودکار، ایندکس پوشه |
| **داده و بینش** `#insights` | آمار خام ← KPI محاسبه‌شده در سرور + شاخص کیفیت انسانی |

مستندات: **[`docs/v7-architecture.md`](docs/v7-architecture.md)** (تصمیم‌ها و دلیل‌ها) و
**[`docs/api-v7.md`](docs/api-v7.md)** (مرجع API).

> **Offline-first.** بدون کلید API، بدون شبکه، بدون Remotion و بدون Chromium کار می‌کند. موتور گرافیک خودش SVG می‌سازد، با resvg رستر می‌کند و فریم‌ها را به ffmpeg می‌دهد.

## ۱. راه‌اندازی سریع

```bash
npm install          # نصب وابستگی‌ها (workspaces)
npm run setup        # بررسی سیستم: موتورها، فونت‌ها، ffmpeg، مدل‌ها
npm run setup:ai     # اتصال Gemini — کلید را می‌گیرد و با فراخوانی واقعی آزمایش می‌کند
npm run verify:ai    # تأیید نهایی: حالت، مدل، مهارت‌ها، یک تولید واقعی
npm run seed         # بارگذاری دستهٔ نمونه + تأیید خودکار
npm run dev          # API روی :4000  +  استودیو روی :5173
```

راهنمای کامل نصب (لینوکس، مک، ویندوز، سرویس دائمی): **[`docs/install.md`](docs/install.md)**

سپس مرورگر را روی **http://localhost:5173** باز کنید.

رندر یک بستهٔ کامل از خط فرمان:

```bash
npm run seed -- --render     # کاور + کاروسل + ریلز، با نوار پیشرفت
npm run seed -- --reset      # پاک‌سازی جدول‌ها قبل از بذرپاشی
```

`--reset` فقط داده‌های دامنه را پاک می‌کند؛ فایل‌های خروجی در `storage/outputs` دست‌نخورده می‌مانند.

## ۲. چرا از صفر بازنویسی شد

نسخهٔ ۵ یک پروتوتایپ بود؛ بازبینی کامل ۲۴ ایراد (۱۱ مورد بحرانی) پیدا کرد. نسخهٔ ۶ هرکدام را در سطح معماری حل می‌کند، نه با وصله:

| ایراد نسخهٔ ۵ | راه‌حل نسخهٔ ۶ |
| --- | --- |
| اجرای دستور از طریق `contentId` (RCE) | همهٔ شناسه‌ها با الگوی zod اعتبارسنجی می‌شوند؛ هیچ‌جا `exec` با ورودی کاربر ساخته نمی‌شود |
| API باز، بدون اعتبارسنجی، خطای خام | هر بدنه با اسکیمای `@atoz/contracts` پارس می‌شود؛ خطاها به پاسخ فارسی و امن تبدیل می‌شوند |
| پیمایش مسیر در آپلود + XSS | مهار مسیر با `path.resolve` + بررسی پیشوند، و escape کامل XML/HTML |
| پایگاه‌دادهٔ JSON (کل فایل خوانده/نوشته می‌شد) | SQLite داخلی Node (`node:sqlite`) در حالت WAL با تراکنش صریح |
| تحویل تکراری و پرش شمارنده‌ها | قاعدهٔ «یک ایده = یک محتوا = یک تحویل»، شناسهٔ صریح هرگز شمارنده را مصرف نمی‌کند، ingest ایندمپوتنت است |
| صف رندر شکننده | صف SQLite با هم‌روندی محدود، بازیابی جاب‌های نیمه‌تمام، لغو، و پیشرفت زنده با SSE |
| وابستگی به ویندوز و PowerShell | فقط Node.js؛ صدای اختیاری از Piper/pyttsx3/edge-tts |
| صدای جعلی و زیرنویس ساختگی | زنجیرهٔ TTS واقعی با اعلام صادقانهٔ نبود موتور + زمان‌بندی زیرنویس تخمینی و برچسب‌گذاری‌شده |
| تقویم جعلی | تبدیل واقعی جلالی/میلادی، هفته از شنبه، تطبیق دقیق تاریخ |
| بدهی فنی و UX | مونوریپو با تایپ‌های مشترک، ۱۰ اتاق، طراحی RTL درجه‌یک |

```

  src/lib/               api.ts (سطح تایپ‌دار کامل) · store.tsx
  src/components/        Shell · ui · Atooz (دستیار صوتی)
  src/rooms/             ۱۰ اتاق
  src/styles/            tokens.css · app.css

scripts/                 dev · setup · seed
```

### خط تولید

```
ایده → Puzzle Block → محتوا (blueprint_pending)
     → تأیید انسانی (approved_for_production)
     → صف رندر → assets → produced
     → تقویم جلالی → published → متریک‌ها
```

هیچ مرحله‌ای قابل پرش نیست و وضعیت‌ها با ماشین حالت در `contracts` تعریف شده‌اند.

## ۴. موتور گرافیک (بدون Remotion)

* `canvas.js` فقط **چیدمان** می‌سازد: `rect / text / circle / polygon / polyline`. یک منبع حقیقت که هم رستر می‌شود و هم فریم‌به‌فریم.
* `motion.js` یک **رجیستری نسخه‌پذیر** از دستورهای حرکت است (۱۷ عدد، هرکدام با `t ∈ [0,1]` → transform/opacity) به‌همراه ۵ گذار بین صحنه‌ها. همان ریاضی هم در پیش‌نمایش مرورگر و هم در رندر ویدئو اجرا می‌شود — عدد جادویی دوگانه وجود ندارد.
* `renderer.js` با resvg تصویر می‌گیرد (≈۵۰ms برای هر فریم ثابت) و فریم‌های ریلز را به ffmpeg می‌دهد (۱۰۸۰×۱۹۲۰، ۳۰fps، H.264).
* نمودارها بومی‌اند: `barChart` راست‌به‌چپ با ناحیهٔ برچسب ثابت، `donut` با کلمپ درصد، `sparkline` با ناحیهٔ پرشده.

افزودن دستور حرکت جدید = یک کلید در `MOTIONS`. هیچ‌جای دیگری تغییر نمی‌کند.

## ۶. ایجنت‌ها، مهارت‌ها و مدل‌ها

چهار ایجنت (آتوز، مدیر بازاریابی، کارگردان محتوا، ویراستار سئو)، شش مهارت تزریقی و
دانش‌پایه برند. هر ایجنت پرامپت، مهارت و قرارداد خروجی مستقل دارد و تنها یک ایجنت
حق اقدام دارد.

**Gemini مسیر اصلی است.** مدل محلی (Ollama) یک گزینهٔ اختیاری است که فقط وقتی
استفاده می‌شود که Gemini نباشد یا خطا بدهد — نه اصل کار. قالب آفلاین آخرین پشتیبان
است و همیشه کار می‌کند.

خروجی مدل با `responseJsonSchema` ساخته‌شده از همان قرارداد zod **در سطح decoder
محدود می‌شود**، سپس دوباره با zod پارس می‌شود. یعنی مدل ساختاراً نمی‌تواند شكل اشتباه
بدهد.

> ⚠️ خانوادهٔ `gemini-2.5` در ۲۰۲۶-۱۰-۱۶ بازنشسته شد. `npm run setup:ai` زنجیرهٔ مدل
> را از مدل‌های واقعاً زندهٔ کلید خودت می‌سازد.

راهنمای کامل: **[`docs/agents-and-skills.md`](docs/agents-and-skills.md)**

## ۷. دستیار Atooz

دکمهٔ شناور در همهٔ اتاق‌ها. چت متنی + ورودی صوتی با `SpeechRecognition` (`fa-IR`). اگر مرورگر پشتیبانی نکند، پیام فارسی صریح می‌دهد. هر کنش مخرب (`requiresConfirmation`) قبل از اجرا دکمهٔ تأیید نشان می‌دهد.

## ۱۰. کارهایی که آگاهانه انجام نشد

* **Remotion / Chromium / Puppeteer** — سنگین، آنلاین، و برای این خط تولید لازم نیست. موتور بومی همان خروجی را می‌دهد.
* **احراز هویت سنگین** — برنامهٔ لوکال تک‌کاربره است؛ بهداشت پایه (اعتبارسنجی، مهار مسیر، بدون `exec`) کافی و متناسب است.
* **۴۰۰ افکت هاردکد** — به‌جای آن یک رجیستری کوچک و تست‌شده که گسترشش یک خط است.
