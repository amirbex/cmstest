# پوشهٔ دارایی‌ها

این پوشه محل ریختن فایل‌های خام شماست. برنامه هر فایل اینجا را با
«مخزن دارایی ← ایندکس پوشه» می‌خواند و در پایگاه‌داده فهرست می‌کند؛
فایل‌ها جابه‌جا نمی‌شوند و ساختار پوشه‌ها حفظ می‌شود.

| پوشه | برای چه |
|---|---|
| `assets/incoming/` | فایل‌های تازه‌رسیده، پیش از دسته‌بندی |
| `assets/brand/` | لوگو، فونت، پالت رنگ، نمونه‌های هویت بصری |
| `assets/raw/` | فوتیج و ویدیوی خام دوربین/موبایل |
| `assets/brand/` و بالاتر | هر ساختار دلخواه دیگری که بسازی |

## استفاده

۱. فایل‌ها را در یکی از این پوشه‌ها بگذار.
۲. در برنامه به **مخزن دارایی** برو.
۳. مسیر مطلق پوشه را بنویس (مثلاً `/home/user/cmstest/assets`).
۴. «ایندکس پوشه» را بزن.

حجم فایل‌ها در گیت ذخیره نمی‌شود؛ فقط ساختار پوشه‌ها. برای نگه‌داشتن
دارایی‌های واقعی در مخزن، `storage/media/` را از `.gitignore` خارج کن یا از
Git LFS استفاده کن.
