# مقاله سئو (فارسی، RTL)

## ساختار اجباری
```
<h2>عنوان اصلی — شامل کلیدواژه، حداکثر ۶۰ کاراکتر</h2>
<p>پاراگراف اول: پاسخ مستقیم به سؤال عنوان در ۲۵ کلمه.</p>
<h3>زیرعنوان ۱</h3>
<p>…</p>
<ul><li>…</li></ul>
<h3>زیرعنوان ۲</h3>
<p>…</p>
```

## قواعد
- فقط `h2`, `h3`, `p`, `ul`, `li`, `strong`, `table`, `thead`, `tbody`, `tr`, `th`, `td`, `blockquote`.
- بدون `h1` (عنوان صفحه جای دیگری است)، بدون `div`، بدون `span`، بدون `style`، بدون `<script>`.
- هر `h3` حداقل یک پاراگراف یا فهرست زیر خودش دارد؛ عنوان بدون محتوا ننویس.
- کلیدواژه‌ی اصلی در `h2`، پاراگراف اول، و یک `h3` بیاید — نه بیشتر، وگرنه کیورد استافینگ می‌شود.
- طول پاراگراف حداکثر ۴ جمله. خواندن روی موبایل.

## پرهیزها
- بدون لینک بیرونی به سایت‌های رقیب.
- بدون جمله‌ی «در این مقاله می‌خوانید» — مستقیم شروع کن.
- بدون ترجمه‌ی ماشینی؛ اصطلاحات فنی را با معادل فارسی + لاتین در پرانتز بیاور.
